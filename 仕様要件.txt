==========================================================
 結婚式写真収集サイト 仕様要件まとめ
==========================================================
最終更新: 2026-07-30

■ サイト構成
----------------------------------------------------------
・アップロードページ(ゲスト用) : https://<デプロイ先URL>/
    - 招待状に記載の「合言葉」を入力して写真・動画を送信
    - お名前は任意入力(ギャラリーに表示されます)
    - ログイン・アプリインストール不要。スマホブラウザで完結
・ギャラリーページ(新郎新婦用) : https://<デプロイ先URL>/gallery
    - 管理用パスコード(合言葉とは別)で保護
    - サムネイル一覧 → タップで原寸表示
    - 投稿者名・投稿日時・件数・合計サイズを表示

■ 収容可能枚数の目安
----------------------------------------------------------
制限は「枚数」ではなく「合計容量」で決まります。
Cloudflare R2 の無料枠は合計 10GB です。

  - スマホ写真のみ(1枚 平均3〜4MB) : 約2,500〜3,000枚
  - 写真+短い動画の混在(想定ケース) : 写真1,000枚+動画数十本程度
  - 動画のみ(1本 平均500MB→95MB制限内): 数十本〜100本程度

10GBを超えても即エラーにはならず、超過分に月額 $0.015/GB の
従量課金が発生します(例: 15GBなら月約12円)。事実上、容量切れで
アップロードできなくなる心配はほぼありません。

■ 1回のアップロードの制限
----------------------------------------------------------
・1ファイルの最大サイズ : 95MB(超過分は端末側で弾いてメッセージ表示)
    - 目安: スマホの4K動画で約1〜2分、フルHDで約5分まで
・受付形式 : 画像すべて(JPEG/PNG/HEIC/HEIF等)、動画すべて(MP4/MOV等)
    - iPhoneのHEIC/HEIFは変換せずそのまま保存されます
・複数枚まとめて選択可能(順次送信・同時3並列)
・失敗したファイルは自動で3回まで再送 → それでも失敗は「再送」ボタン
・連続送信の制限 : 同一端末から1分間に60リクエストまで
    (超えると少し待ってから自動再開します)

■ アップロードした写真はどこで見られるか
----------------------------------------------------------
1. ギャラリーページ(閲覧用)
   https://<デプロイ先URL>/gallery を開き、管理用パスコードを入力。
   ※ゲスト用の合言葉では開けません。パスコードは新郎新婦のみが保持。
2. 一括ダウンロード(保存用)
   rclone を使って R2 バケットから全件を一括取得します。
   手順は README.md「3. 写真の一括ダウンロード」参照。
3. Cloudflareダッシュボード(管理用)
   R2 → バケット wedding-photos でファイル一覧・使用量・削除操作が可能。

■ 合言葉・パスコードの管理
----------------------------------------------------------
・ゲスト用合言葉   : GUEST_PASSCODE(招待状に記載して配布)
・管理用パスコード : ADMIN_PASSCODE(新郎新婦のみ。合言葉と別のものに)
・どちらも wrangler secret で登録し、コードには含まれません
・変更したいとき : npx wrangler secret put GUEST_PASSCODE → npx wrangler deploy

■ その他の注意点
----------------------------------------------------------
・本番サイトは Cloudflare Workers 上で動作します。
  GitHub Pages のURLは「画面デザイン確認用のデモ」であり、
  サーバ機能(アップロード・ギャラリーAPI)は動きません。
  ゲストに配るQRコードは必ず Cloudflare の workers.dev URL で作ること。
・写真の削除機能はサイト上にはありません。
  誤投稿の削除は Cloudflareダッシュボード(R2)から行います。
・ギャラリーは原寸画像をそのまま表示するため、千枚規模では
  スクロールに応じて順次読み込みます(通信量に注意。Wi-Fi推奨)。
・HEIC画像のギャラリー表示可否は閲覧側ブラウザに依存します
  (iPhone/MacのSafariは表示可。保存データ自体は劣化なくそのまま)。
・動画のサムネイルは生成しません(▶アイコン表示。タップで再生)。
・式が終わったら: 全件を一括ダウンロード → バケットを空にして削除
  すれば、以後の課金は一切発生しません。
・無料枠の消費状況は Cloudflareダッシュボード → R2 で確認できます。

■ 運用フロー(当日まで)
----------------------------------------------------------
1. README.md の手順で Cloudflare にデプロイ
2. 合言葉・管理パスコードを wrangler secret で設定
3. npm run qr -- <デプロイURL> でQRコード(qr.png)を生成
4. 招待状・席次表・受付カード等にQRコードと合言葉を記載
5. 式後、ギャラリーで閲覧 & rclone で一括ダウンロード
