==========================================================
 結婚式写真収集サイト 仕様要件まとめ
==========================================================
最終更新: 2026-10-04

■ サイト構成
----------------------------------------------------------
ページは1枚だけです: https://<デプロイ先URL>/
・上部: アップロード
    - 合言葉は不要。QRコードからそのまま送信できます
    - お名前は任意入力(写真一覧に表示されます)
    - ログイン・アプリインストール不要。スマホブラウザで完結
・下部: みんなの写真
    - 投稿された写真・動画が新しい順に並ぶ(スクロールに応じて順次表示)
    - 投稿者名・投稿日時・件数・合計サイズを表示
    - タップで大きく表示 →「端末に保存」で保存
        iPhone/Android: 共有メニューの「画像を保存」で写真アプリへ
                        (iPhoneは写真の長押しでも保存可)
        PC            : 通常のファイルダウンロード
    - まとめて保存:「選択」→ 写真をタップして選ぶ →「◯件を保存」
        スマホは一度に50件・合計400MBまで(メモリ保護のため)。PCは無制限
        iPhone : 共有メニューの「◯枚の画像を保存」で写真アプリへ
        PC     : 1件ずつ連続ダウンロード
    - 送信が終わると自動で一覧が更新される。他の人の新着は「最新にする」で反映
※ 旧URL /gallery は / へ自動転送。ライブムービー(/live)は廃止済み。

■ 収容可能枚数の目安
----------------------------------------------------------
制限は「枚数」ではなく「合計容量」で決まります。
Cloudflare R2 の無料枠は合計 10GB です。

  - スマホ写真のみ(1枚 平均3〜4MB) : 約2,500〜3,000枚
  - 写真+短い動画の混在(想定ケース) : 写真1,000枚+動画数十本程度
  - 動画のみ(1本 平均500MB→95MB制限内): 数十本〜100本程度

一覧用の縮小版(1枚約50KB)も保存しますが、1,000枚で約50MBと
ごくわずかです。
10GBを超えても即エラーにはならず、超過分に月額 $0.015/GB の
従量課金が発生します(例: 15GBなら月約12円)。

■ 1回のアップロードの制限
----------------------------------------------------------
・1ファイルの最大サイズ : 95MB(超過分は端末側で弾いてメッセージ表示)
    - 目安: スマホの4K動画で約1〜2分、フルHDで約5分まで
・受付形式 : 画像すべて(JPEG/PNG/HEIC/HEIF等)、動画すべて(MP4/MOV等)
    - iPhoneのHEIC/HEIFは変換せずそのまま保存されます
・複数枚まとめて選択可能(順次送信・同時3並列)
・失敗したファイルは自動で3回まで再送 → それでも失敗は「再送」ボタン
・連続送信の制限 : 同一IPから1分間に60枚まで
    (超えると少し待ってから自動再開します)

■ アップロードした写真はどこで見られるか
----------------------------------------------------------
1. サイトの下部「みんなの写真」(閲覧・1枚ずつ保存)
   誰でもパスコードなしで見られます。
2. 一括ダウンロード(全件保存用)
   rclone を使って R2 バケットから全件を一括取得します。
   手順は README.md「3. 写真の一括ダウンロード」参照。
3. Cloudflareダッシュボード(管理用)
   R2 → バケット wedding-photos でファイル一覧・使用量・削除操作が可能。

■ その他の注意点
----------------------------------------------------------
・合言葉を廃止したため、URLを知っている人は誰でも
  写真の閲覧・保存・投稿ができます。
  検索エンジンには載らない設定(noindex)にしていますが、
  QRコードやURLをSNS等に公開しないようご注意ください。
・本番サイトは Cloudflare Workers 上で動作します。
  GitHub Pages のURLは「画面デザイン確認用のデモ」であり、
  アップロード・写真一覧は動きません。
  ゲストに配るQRコードは必ず Cloudflare の workers.dev URL で作ること。
・写真の削除機能はサイト上にはありません。
  誤投稿の削除は Cloudflareダッシュボード(R2)または
  README.md「4. 写真の削除」のコマンドで行います。
・一覧は縮小版を表示するため、千枚規模でもスマホで軽く見られます。
  縮小版はアップロードした端末で作るため、Android等でHEICを送った場合は
  縮小版が作れず「HEIC」の表示になります(保存は可能)。
・動画のサムネイルは生成しません(▶アイコン表示。タップで再生)。
・式が終わったら: 全件を一括ダウンロード → バケットを空にして削除
  すれば、以後の課金は一切発生しません。
・無料枠の消費状況は Cloudflareダッシュボード → R2 で確認できます。
・Cloudflareのログインは数か月で期限切れになります。デプロイ時に
  エラーが出たら npx wrangler login で再ログインしてください。

■ 運用フロー(当日まで)
----------------------------------------------------------
1. README.md の手順で Cloudflare にデプロイ
2. npm run qr -- <デプロイURL> でQRコード(qr.png)を生成
3. 招待状・席次表・受付カード等にQRコードを記載
4. 当日: ゲストが送信 → その場で「みんなの写真」で見て保存
5. 式後、rclone で全件を一括ダウンロード
